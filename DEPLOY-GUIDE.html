🌐 นำ English Quest ขึ้นออนไลน์

คู่มือทำให้เด็กหลายคนเล่นพร้อมกันในแมพเดียว (Real-time Multiplayer)

📦 ไฟล์ในชุดนี้

โฟลเดอร์ eq-mp มีไฟล์ที่ต้องอัปขึ้นเซิร์ฟเวอร์ทั้งหมด:

server.jsตัวเซิร์ฟเวอร์ (Node + WebSocket)
package.jsonรายการ dependency + คำสั่งรัน
public/index.htmlตัวเกม (client)
render.yamlตั้งค่า deploy อัตโนมัติ
.gitignoreไฟล์ที่ไม่ต้องอัป
💡 เซิร์ฟเวอร์ทำหน้าที่ 2 อย่าง: (1) ส่งหน้าเกมให้ผู้เล่น และ (2) เป็นตัวกลางส่งตำแหน่ง/แชทระหว่างผู้เล่น ทุกคนจึงเห็นกันแบบเรียลไทม์

🧪 ทดสอบบนเครื่องตัวเองก่อน (ไม่บังคับ)

ถ้ามี Node.js (เวอร์ชัน 18 ขึ้นไป) ติดตั้งแล้ว เปิด Terminal ในโฟลเดอร์ eq-mp แล้วพิมพ์:

# ติดตั้ง dependency (ครั้งแรกครั้งเดียว)
npm install

# รันเซิร์ฟเวอร์
npm start

จากนั้นเปิดเบราว์เซอร์ไปที่ http://localhost:3000 — ลองเปิด 2 แท็บ ใส่ชื่อต่างกัน กด "เริ่มเล่น" จะเห็นตัวละครอีกตัวเดินในแมพเดียวกัน

✓ ถ้าเห็นตัวละครอีกคนเดินตามได้ แปลว่าระบบ multiplayer ทำงานถูกต้อง พร้อมนำขึ้นออนไลน์

🚀 วิธีที่ 1: Render แนะนำ — ฟรี

ง่ายและรองรับ WebSocket เต็มรูปแบบ มีไฟล์ render.yaml ตั้งค่าให้แล้ว

1
สมัคร render.com (ฟรี) — ล็อกอินด้วย GitHub ได้เลย
2
อัปโฟลเดอร์ eq-mp ขึ้น GitHub repository ใหม่ (ลากไฟล์ทั้งหมดเข้าไป commit)
3
ใน Render กด New → Web Service แล้วเลือก repo ที่เพิ่งสร้าง
4
Render จะอ่าน render.yaml เอง — ตรวจว่า Build = npm install, Start = npm start แล้วกด Create Web Service
5
รอ build เสร็จ (~1-2 นาที) จะได้ลิงก์เช่น https://english-quest-xxx.onrender.com — นี่คือลิงก์เกมของคุณ แจกให้เด็กได้เลย
⚠️ แพ็กเกจฟรีของ Render จะ "หลับ" หลังไม่มีคนเล่น ~15 นาที ครั้งแรกที่เปิดอาจรอ ~30 วินาทีให้ตื่น หลังจากนั้นจะลื่นปกติ

🚂 วิธีที่ 2: Railway

  • สมัคร railway.app
  • กด New Project → Deploy from GitHub repo เลือก repo eq-mp
  • Railway ตรวจเจอ Node เอง รันด้วย npm start อัตโนมัติ
  • ไปที่ Settings → Networking → Generate Domain เพื่อรับลิงก์สาธารณะ

🎏 วิธีที่ 3: Glitch ไม่ต้องใช้ GitHub

  • เข้า glitch.com กด New Project → Import from GitHub หรือสร้าง Node project แล้วลากไฟล์เข้าไป
  • Glitch รัน npm start ให้เอง และรองรับ WebSocket
  • ลิงก์จะเป็นแบบ https://ชื่อโปรเจกต์.glitch.me
💡 Glitch เหมาะถ้าอยากแก้โค้ดออนไลน์โดยไม่ต้องตั้ง GitHub แต่โปรเจกต์ฟรีจะหลับเร็วกว่า Render

🎮 วิธีเล่นเมื่อขึ้นออนไลน์แล้ว

  1. แจกลิงก์เซิร์ฟเวอร์ให้นักเรียน (เช่นผ่าน QR code บนกระดาน)
  2. นักเรียนเปิดลิงก์ → เลือกชั้น → ตั้งชื่อ → สร้างตัวละคร → กด "เริ่มเล่น"
  3. ทุกคนที่อยู่ โซนเดียวกัน จะเห็นตัวละครของกันและกัน พร้อมชื่อและเลเวลลอยอยู่เหนือหัว
  4. มุมขวาบนแสดง จำนวนคนออนไลน์ 👥 และสถานะการเชื่อมต่อ
  5. ใช้ช่อง 💬 แชท คุยกับคนในโซนเดียวกันได้
✓ ความคืบหน้า เลเวล และไอเทม เป็นของแต่ละคน (เก็บในเครื่องตัวเอง) — เซิร์ฟเวอร์แค่ซิงค์ตำแหน่งและแชทให้เห็นกัน

🔧 เคล็ดลับ & แก้ปัญหา

แยกโฮสต์ client กับ server

ถ้าอยากวางตัวเกมไว้ที่อื่น (เช่น GitHub Pages) แต่ใช้เซิร์ฟเวอร์ที่ Render ให้เปิดเกมด้วยลิงก์แบบนี้:

https://ที่อยู่เกมของคุณ/?server=wss://english-quest-xxx.onrender.com

เกมจะเชื่อมต่อไปยังเซิร์ฟเวอร์ที่ระบุใน ?server= แทน

เล่นคนเดียวก็ยังได้

ถ้าเปิดไฟล์ public/index.html ตรงๆ โดยไม่มีเซิร์ฟเวอร์ เกมจะขึ้นสถานะ "เล่นแบบออฟไลน์" และเล่นคนเดียวได้ตามปกติ — ระบบ multiplayer จะปิดเงียบไปเอง

เชื่อมต่อหลุด

ถ้าเน็ตหลุด เกมจะพยายามต่อใหม่อัตโนมัติทุก ~2.5 วินาที โดยไม่ต้องรีเฟรช

⚠️ ต้องใช้ https (และ wss://) เมื่อขึ้นออนไลน์จริง เบราว์เซอร์จะบล็อก ws:// ที่ไม่เข้ารหัสบนหน้าเว็บ https — แพลตฟอร์มข้างบนให้ https มาอยู่แล้ว ไม่ต้องตั้งเพิ่ม
